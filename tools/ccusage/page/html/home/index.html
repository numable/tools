Claude Code 用量

会话、消息与 token 消耗

1

在 Claude Code 里装采集插件

依次运行这两条命令。插件只读取用量数字，代码和对话内容不会离开你的电脑。

/plugin marketplace add numable/numable-usage /plugin install numable-usage
2

把读取令牌填进来

装好插件后，在 Claude Code 里运行 /numable-usage，把它给出的读取令牌粘贴到凭证设置里。令牌只能读你自己的用量数字。

只上传汇总数字：每天的消息数、会话数、token 用量、模型占比、工具调用次数和改动行数，不含分支名、文件路径和任何对话内容。项目默认只显示编号，在插件里打开后才显示文件夹名。
