# Numable official tools

A **tool** is a content bundle (XBundle) for [Numable](https://get.numable.app): a few widgets for your
dashboard and home screen, plus the pages behind them. Each one is plain files — layout in `.rcn`, data
flows in `.df` / `.af`, pages in `.xpage` / HTML — and fetches its data directly from the device. There is no
Numable server in between.

## Start your own tool from one of these

```bash
git clone https://github.com/numable/tools
npx numable init my-weather --from tools/tools/weather   # copy with a fresh identity
cd my-weather
npx numable check && npx numable run && npx numable render
```

`init --from` gives the copy a new id and version 1 and strips the store signature, so it is yours to
change. The full authoring guide ships with the CLI (`npx numable docs`) and is online at
[docs.numable.app](https://docs.numable.app) (`llms.txt` for AI agents).

Tools here are generated by our own pipeline; please don't hand-edit them in place — derive a copy as above.

## 从这里起步写自己的工具

```bash
git clone https://github.com/numable/tools
npx numable init my-weather --from tools/tools/weather   # 复制一份,重新生成身份
cd my-weather
npx numable check && npx numable run && npx numable render
```

`init --from` 会给副本一个新 id、版本归 1、去掉商店签名,之后就是你自己的工具。完整的创作指南随命令行发布
(`npx numable docs`),线上见 [docs.numable.app](https://docs.numable.app)(给 AI 用的入口是 `llms.txt`)。

这里的工具由我们的生成流程产出,请不要在原处手改,按上面的方法派生一份再改。
